개요

이 프로젝트가 무엇이고 무엇을 하는지 한눈에.

QR을 통한 간편 회원가입을 목적으로 한 이번 MCN 시연 데모입니다.

1

화면 흐름 (QR → 가입 → 초대 링크)

사용자가 거치는 화면 순서와 라우팅.

행사장에서 아래 주소로 접속하면 QR 코드가 표시됩니다.
https://aisum.com/en/aediv-qr

카메라를 통하여 QR 스캔을 진행하면 가입 페이지로 이동합니다.

2

가입 폼 · 필드와 검증

Company / Name / Email / Position 필드와 이메일 검증 규칙.

아래 주소로 접속하면 가입 폼이 표시됩니다.
https://aisum.com/en/aediv-agency

붉은색 밑줄 부분은 필수 입력 값, 파란색 밑줄 부분은 옵션 값입니다.

  • Company Name — 회사명 필수
  • Name — 이름 필수
  • Email — 이메일 필수
  • Position — 직책 선택
!
Email 형식Email은 반드시 이메일 형식이어야 합니다. (예: name@example.com)
3

초대 링크 (INCLUDES)

응답 link를 받아 Copy link로 노출하는 화면.

STEP 초대 링크 공유
  • 1
    Copy link 버튼 클릭

    Copy link 버튼을 클릭하여 초대 링크를 복사합니다.

  • 2
    새 창에 붙여넣기

    새 창(브라우저)을 열어 주소창에 붙여넣기하여 이동합니다.

4

크롬 웹스토어 페이지 (aedi-v) 설치

Chrome 웹스토어에서 AEDI-V 확장 프로그램을 설치.

Add to Chrome 버튼을 클릭한 뒤 설치를 진행합니다.

5

결과 확인

가입 후 지급된 크레딧을 구독 상세 화면에서 확인합니다.

결과는 https://global.aedi.ai/aediv/userinfo 에서 확인합니다.
