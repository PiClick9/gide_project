개요

대시보드가 보여주는 것과 데이터 모델 요약.

https://aisum.com/en/aediv-dashboard 페이지의 대시보드 동작 시연 테스트 페이지입니다.

1

날짜 범위 & 필터

Today / Last 7 days / This Month / Last Month 프리셋과 달력.

  • 현재 날짜가 디폴트로 적용됩니다. 종료일 = 오늘
  • Today / Last 7 days / This Month / Last Month 프리셋이 있으며, 초기 기본값은 Last 7 days가 적용됩니다.

각 버튼을 클릭하면 대시보드의 그래프가 변동되는 것을 확인할 수 있습니다.

2

요약 카드

Sign-ups · Subscribers · Conversion · Payment · Markup.

선택한 날짜 범위의 데이터를 5개 지표로 요약합니다. 아래 그래프와 같은 데이터를 카드 형태로 한눈에 보여줍니다.

지표의미예시 값
Sign-ups가입자 수 (신규 가입)24
Subscribers구독(결제)한 크리에이터 수14
Conversion Rate전환율 = 구독 ÷ 가입58%
Payment Amount총 결제 금액$347.6
Markup대행 마진(수수료)$69.52
i
카드 하단 숫자각 카드 아래의 작은 값은 이전 기간 대비(델타), 초록 화살표는 증감 추이를 나타냅니다.
3

그래프, 크리에이터 표

일/주별 그래프와 크리에이터 표, Add Creator 동작.

  • Daily / Weekly — 버튼을 클릭할 수 있으며, 각각 그래프를 일자별 / 주별 단위로 표시합니다.
  • Add Creator — 클릭하면 그래프에 표시된 마지막 날짜에 Starter Standard Pro 플랜 중 랜덤으로 그래프·표에 추가됩니다.
