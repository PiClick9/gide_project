개요

대시보드가 무엇인지 한눈에.

https://aisum.com/en/aediv-dashboard 페이지의 대시보드 동작 시연 테스트 페이지입니다.

1

크리에이터 추가 / 삭제

Add Creator / Delete로 크리에이터를 하나씩 추가·삭제.

  • Add Creator — 클릭하면 그래프에 표시된 마지막 날짜에 Starter Standard Pro 플랜 중 랜덤으로 크리에이터가 그래프·표에 추가됩니다.
  • Delete — 표 각 행의 Delete 버튼으로 해당 크리에이터를 삭제하면 그래프·요약 카드에 즉시 반영됩니다.
2

그래프 탭 (Daily / Weekly)

그래프 상단 탭으로 집계 단위를 전환.

그래프 우측 상단의 Daily / Weekly 탭을 눌러 그래프의 집계 단위를 전환합니다.

  • Daily — 일자 기준. 선택한 기간의 실제 날짜별로 컬럼을 표시합니다. (하루 = 한 컬럼)
  • Weekly — 주 기준. 같은 기간을 주 단위로 묶어 컬럼을 표시합니다. (한 주 = 한 컬럼)

컬럼 수에 따라 막대 너비가 자동으로 조정됩니다(컬럼이 적으면 넓게, 많으면 얇게).

3

날짜 범위

기간 프리셋 탭과 시작·종료일 달력으로 조회 기간 설정.

  • 종료일 기본값은 오늘이며, 종료일은 오늘 이후(미래)를 선택할 수 없습니다(최대 오늘).
  • 시작·종료일 달력을 클릭해 기간을 직접 지정할 수 있습니다. 단, 시작일은 종료일을 넘을 수 없습니다.

우측 상단의 기간 프리셋 탭을 클릭하면 기간이 자동으로 설정되고, 표·그래프·요약이 그 기간으로 필터링됩니다.

탭조회 기간
Today오늘 하루
Last 7 days 기본값최근 7일 (오늘 포함)
This Month이번 달 1일 ~ 오늘
Last Month지난 달 1일 ~ 말일
4

요약 카드

선택 기간의 데이터를 5개 지표로 요약.

선택한 날짜 범위의 데이터를 5개 지표로 요약합니다. 아래 그래프와 같은 데이터를 카드 형태로 보여줍니다.
